# Valuaris

**Value over noise.**

Early mockup for a small, deliberately focused value-investing dashboard.

## V0.1

The overview page currently uses placeholder market prices and lets you edit:

- intrinsic value range per share
- expected annual growth rate
- shares owned
- 5-year / 10-year forecast horizon

From those inputs it calculates:

- current portfolio market value
- conservative and optimistic intrinsic portfolio value
- conservative and optimistic future portfolio value
- market-price / intrinsic-value ratio

The mockup deliberately does **not** show purchase price, profit/loss, or performance.

Open `index.html` in a browser to try it.
